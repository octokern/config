# Support

- **Bug reports:** use the [Bug report](https://github.com/octokern/config/issues/new?template=bug_report.yml) issue form.
- **Feature requests:** use the [Feature request](https://github.com/octokern/config/issues/new?template=feature_request.yml) form.
- **Usage questions:** use [GitHub Discussions](https://github.com/octokern/config/discussions) when enabled.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not report vulnerabilities publicly.

When asking for help, include the `@octokern/config` version, Node.js version, package manager, module format (ESM/CommonJS), relevant NestJS major (if applicable), a minimal reproduction and the complete error message with secrets removed.

Please do not paste `.env` files, access tokens, API keys, private certificates or production configuration into issues or discussions.
