# Security Policy

## Supported versions

Security fixes are provided for the latest published `1.x` release. Please upgrade to the latest patch release before reporting an issue.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues, discussions or pull requests.

Use GitHub's **Report a vulnerability** feature in the repository's Security tab to create a private vulnerability report:

https://github.com/octokern/config/security/advisories/new

Include the affected package version, Node.js version, reproduction steps, expected impact and any proof of concept that can be shared safely. Do not include live credentials, production secrets or personal data.

If private vulnerability reporting is not enabled for the repository, contact the maintainer privately through the email address listed in the npm package metadata.

We will acknowledge reports as soon as practical, investigate the issue, coordinate a fix and publish an advisory when appropriate. Please allow maintainers reasonable time to prepare a fix before public disclosure.
